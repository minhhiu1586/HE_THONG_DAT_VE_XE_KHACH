# Tai lieu du an

Thư mục này lưu toàn bộ tài liệu phân tích, thiết kế và kế hoạch triển khai của hệ thống đặt vé xe khách trực tuyến.

## Nhom tai lieu

- `requirements/`: yêu cầu hệ thống, SRS và use cases.
- `diagrams/`: các sơ đồ phân tích và thiết kế.
- `database/`: thiết kế cơ sở dữ liệu, schema và dữ liệu mẫu.
- `plans/`: kế hoạch làm việc, phân công nhiệm vụ và tiến độ.
